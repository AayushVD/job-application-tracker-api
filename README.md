# Job Application Tracker API

A planned backend application for organizing job applications, tracking recruitment progress, and managing interview schedules through a RESTful API.

## Project Status

Planning — implementation has not started.

## Planned Features

- Create, retrieve, update, and delete job application records
- Track application status, including Applied, Assessment, Interview, Offer, and Rejected
- Store company details, job titles, application dates, and notes
- Manage interview schedules and deadlines
- Filter applications by company and application status
- Validate incoming requests and handle errors
- Persist application data in a relational database
- Test API endpoints and business logic

## Planned Technology Stack

- **Language:** Java
- **Backend Framework:** Spring Boot
- **Database:** MySQL
- **API Architecture:** REST
- **Testing:** JUnit and Spring Boot Test
- **Version Control:** Git and GitHub
